# Current Decisions

## Purpose

List important decisions made so far.

## Decisions

- Use real current-season NBA data for OVR.
- Use NBA-derived stat fields for detailed attributes.
- Star-up increases attributes but not OVR.
- Attributes are uncapped.
- Players have 3 base skill slots and 2 special learned skill slots.
- Base slot 3 unlocks at OVR 85+.
- Special slot 1 unlocks at Star 1.
- Special slot 2 unlocks at Star 5.
- Skills must affect the match engine.
- AI must use skills too.
- Strong combos must have counters.
- Maintain project memory in this Obsidian LLM Wiki.

## Open Questions

- Final OVR formula.
- Final attribute display design.
- Final skill art style.
