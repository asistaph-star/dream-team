# Combo Counter Design

## Purpose

Define the design rule that every strong combo must have counterplay.

## Current Facts

The user wants tactical lineup building, where players can build around combos but opponents can answer them.

Good combo design:

- Has a setup step
- Has a payoff step
- Has visible match-log feedback
- Has at least one counter
- Can be disrupted by lineup choices or play choices

## Examples

Stamina drain:

- Setup: Chain Pass X applies Debt.
- Payoff: Lung Burner X and Debt Collector X drain/spread stamina.
- Counter: Cold Timeout X, Iron Motor, substitutions.

3PT foul trap:

- Setup: Red Dot X applies Exposed.
- Payoff: Four-Point Bait X pressures Exposed defenders.
- Counter: Clean Contest X, Discipline Wall, Composure X, Shadow Guard.

Trap defense:

- Setup: Cage Step X, Corner Trap X, Dead Air X apply Hooked/Pinned/Static.
- Payoff: stamina tax, trigger suppression, turnovers.
- Counter: passive skills, safe handlers, Cold Timeout X.

## Open Questions
