# Game Direction

## Purpose

Define the identity of the Dream Team / G10K basketball manager game.

## Current Facts

The game is a basketball dream-team manager with tactical lineup building, real NBA current-season player identity, star-up growth, and skill combos with counterplay.

The game should not feel like a direct copy of the reference game. The reference can inspire structure, but mechanics should be original.

Core feel:

- Tactical team-building
- Real NBA performance grounding
- Stamina management
- Skill combos
- Counter systems
- Match logs that prove mechanics are working

## Non-Negotiables

- Mechanics must affect gameplay, not only UI.
- OVR must remain tied to real NBA data.
- Star-up must improve attributes without inflating OVR.
- Strong combos need counters.

## Open Questions

- What exact OVR formula will be used once the NBA stat import is complete?
- How often should current-season NBA data refresh?
- Should old-season player cards use historical-season data or current player data?
